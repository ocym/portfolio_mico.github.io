## Run locally

Open `index.html` in a browser. The portfolio is a static HTML/CSS/JavaScript site and does not require a build step. Google Fonts are loaded from the internet.

## Publish with GitHub Pages

1. Upload `index.html`, `README.md`, and the `assets/` folder to the root of the [`ocym/portfolio_mico.github.io`](https://github.com/ocym/portfolio_mico.github.io) repository.
2. Commit changes to the `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch **main**, folder **/(root)**.
4. Visit https://ocym.github.io/portfolio_mico.github.io/ after deployment.
5. If an image does not appear, confirm its exact filename and path under `assets/`, then hard-refresh the page.
