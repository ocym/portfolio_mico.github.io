# Mico Rosales Portfolio

## Files
- `index.html` — responsive portfolio website
- `assets/mico-profile.png` — your supplied profile picture

## Publish on GitHub Pages
1. Open the `mico.github.io` repository.
2. Upload `index.html` and the entire `assets` folder to the repository root.
3. Commit the changes to your `main` branch.
4. In **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)`.
5. Visit `https://mico.github.io/`.

The portfolio includes your Instagram, TikTok, and LinkedIn links. The projects section contains only Fit & Fierce and KaPiyu.
